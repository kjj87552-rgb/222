### 4.2 韩漫半厚涂渲染体系——本版核心基底

**这是全系列第一个非赛璐璞系统。所有渲染描述必须使用半厚涂语言。**

**半厚涂(伪厚涂)核心特征：**
- **颜色过渡柔和自然**——不同色块之间以柔和渐变过渡(不像赛璐璞的硬边分界)
- **阴影边缘模糊**——光暗面分界线不明显，以渐变过渡
- **线稿与色块融合**——线条不是独立的黑色层，而是随色块变色并在边缘融入上色
- **质感表达力强**——可以表现丝绸/毛织/皮革/水滴/金属的不同材质光泽
- **高光有层次**——不只是一个白点，而是有形状有渐变的柔和高光(如头发的带状高光)

**角色精细度分级(由styleLevel决定)：**

| 精致度 | 面部 | 头发 | 瞳孔 | 服饰 | 适用角色 |
|-------|------|------|------|------|---------|
| **精致华丽** | 五官极精细/睫毛单根可数/唇部光泽/腮红自然渐变 | 多层渐变+丝绸高光带+发丝级细线+飘动质感 | 三层渐变环+双高光+睫毛投影+瞳孔反射 | 面料质感可辨/褶皱精细/配饰细节/品牌感 | 高颜值核心角色/重要场合/特写镜头 |
| **清新自然** | 五官清晰但不过度精细/自然腮红/淡妆感 | 色块渐变+简化高光+整体飘动 | 双层渐变+单高光 | 日常穿搭/材质概括/干净利落 | 日常场景/远景中景/配角 |
| **中性休闲** | 五官简洁/线条为主 | 色块+简单阴影 | 单层+高光 | 轮廓为主 | 远景路人/不重要配角 |

**每个角色在特写镜头自动升一级精致度，在远景自动降一级。**

### 4.3 韩漫摄影感光影系统——"光即滤镜"

**核心原则：韩漫的光不是用来"照亮场景"的(日系功能光)，也不是用来"制造恐惧"的(悬疑灵异)——是用来"创造美感和情感氛围"的。韩漫的光=韩剧的摄影滤镜。**

**光影情境表（心动光影）：**

| 光影情境 | 光源/光质 | 画面效果 | 情感功能 | 适用场景 |
|---------|---------|---------|---------|---------|
| **Golden Hour(黄金时刻)** | 黄昏/日落方向暖橙光 | 全画面染上暖橙/蜂蜜色调。角色皮肤呈现温暖光泽。长影子。天空渐变(橙→粉→紫) | 最浪漫的光——告白/重要对话/分别/回忆 | 放学路/天台/海边/公园 |
| **逆光(Backlight)** | 光源在角色背后 | 角色轮廓被金色/暖光rim light勾边(发丝/肩/臂外轮廓发光)。面部柔和暗面。发丝半透明 | "TA在发光"——仰慕/心动/初见 | 走廊/教室窗边/任何背对窗户或阳光 |
| **侧光(Side Light)** | 光源在角色侧面(通常窗户) | 面部一半明一半柔暗(不是硬阴影——渐变过渡)。明面高光柔和。暗面可见但不压抑 | 立体感最强——突出颜值/制造深邃氛围 | 教室靠窗/咖啡厅/任何侧窗场景 |
| **窗光散射** | 窗户进入的柔化散射光 | 光以柔和方式填满空间——无明显方向性。可见光柱中灰尘粒子缓浮(半透明bokeh) | 温暖/安静/日常的美——"普通的一天很美" | 教室/图书馆/家中 |
| **柔焦光晕(Soft Glow)** | 无特定光源——画面后期效果 | 画面整体叠加柔和发光层——边缘微微光晕。高亮区域向外散射柔光 | ★心动滤镜★——心动瞬间专用 | 心动/牵手/亲密距离/深情凝视 |
| **夜间暖光(Night Warm)** | 路灯/店铺灯光/手机屏幕 | 暖黄/暖橙光源在夜间冷蓝环境中创造温暖岛屿。角色面部被暖光照亮 | 夜晚的浪漫——深夜对话/送回家/便利店前 | 夜间街道/便利店/校门口路灯下 |
| **阴天柔光(Overcast)** | 云层散射——无影/无方向 | 全画面均匀柔光。色调偏冷灰但不压抑。无明显阴影 | 平静/日常/微忧——适合暗恋/独处/思考 | 任何室外阴天 |
| **雨中光(Rain Light)** | 灰调天光+雨滴折射 | 画面整体灰蓝调。水面反射/雨滴在表面的高光。衣物湿润后颜色加深+光泽改变 | 雨=情感催化剂——雨中共伞/淋雨/等待 | 雨天任何场景 |
| **室内暖调(Indoor Warm)** | 室内灯光(暖白/暖黄) | 空间被温暖充满。人物皮肤暖调。材质质感丰富(木/布/纸的温度) | 安全/亲密/家的感觉 | 咖啡厅/家中/教室(开灯) |
| **手机屏幕光(Screen Light)** | 手机/电脑屏幕冷白光 | 面部在暗环境中被小范围冷白光照亮。瞳孔中映出屏幕内容 | 深夜独处——看消息/等回复/看照片 | 深夜卧室/被窝中 |

**半厚涂阴影法则：**
- 阴影边缘始终模糊渐变(非赛璐璞硬边)
- 阴影色不是灰/黑——而是偏暖(阳光场景)或偏冷(阴天/夜间)的有色阴影
- 面部阴影以自然的鼻影/颧骨影/下巴影为主——像化妆修容一样"美化"面部结构
- 脖颈阴影、锁骨阴影、下颌线阴影=韩漫角色的"颜值三件套"

**粒子与氛围效果（韩漫专属）：**

| 粒子/氛围 | 视觉表现 | 情感功能 |
|----------|---------|---------|
| **光柱灰尘(Dust Motes)** | 窗光/逆光中的半透明圆形bokeh光点——缓慢飘浮 | 时间变慢了/这一刻很美/日常的诗意 |
| **樱花/花瓣(季节)** | 浅粉色花瓣以缓慢弧线飘落——半透明+旋转 | 春天/浪漫/初恋(注意：不是日系满屏花背景——是实际飘落的花瓣) |
| **雨滴** | 斜线雨滴前景层+落在物体表面的水花+积水反射 | 情感催化剂/隔绝外界/两人世界 |

### 4.5 服饰与造型视觉系统——韩漫独有维度

- 通读 `groupNote` 和所有 shots，理解本组的叙事功能和情绪弧线
- 叙事功能：相遇/日常互动/暧昧升温/心动桥段/告白/争执/和好/独处/回忆/搞笑/群戏
- **心动等级判断**——S/A/B/C/D → 决定光影滤镜强度和演出力度（结合 `directorNote` 推断）
- **精致度判断**——根据角色 `styleLevel` + 上游 `cameraWork` 景别 → 决定渲染精细度
- **光影情境选择**——根据场景库 `timeOfDay` + `groupNote` 中的光影方向 → 选择光影方案

**b. 时间段映射（非自由切分）**
- **时间段数量 = shots 数量**，每个 shot 对应一个时间段
- 时间起止由 `timeline` 逐个累加计算
- 例：shot[0] 4s + shot[1] 5s + shot[2] 5.5s = 14.5s
  → 【0-4秒】【4-9秒】【9-14.5秒】
- **韩漫的节奏偏慢——一个心动桥段可以占整个时间段(慢慢展开、慢慢心动)**
- 心动瞬间的Hold(定格)比日系更长——2-3秒的凝视/对视是正常的

**c. 每段韩漫风格执行细化**
对每个 shot/时间段，你做以下工作：
- **转场**：继承 `transition`，翻译为韩漫转场术语
- **镜头**：继承 `cameraWork`，以韩漫摄影感运镜语言展开（**必须将实拍/3D术语转换为韩漫对等表达**）
- **主体动作**：基于 `visualsAction` 进行**韩漫半厚涂物理细节文学化**（半厚涂渲染 + 光影滤镜 + 微表情 + 距离管理 + 服饰质感 + 粒子氛围）
- **音效**：以 `sfx` 为骨架，补全三层韩剧OST感音效
- **旁白/对话**：从 `audio` 透传，格式化为手记格式

**d. @引用嵌入（最高优先级规则）**

规则与通用版完全相同：
- **@角色名**：每次提及必须带@
- **@场景名**：声明+首段锚定，后续段可指代
- **@道具名**：每次提及必须带@
- 检索机制：输出前扫描 video_prompt 全文——角色名和道具名零裸名；场景名在声明区块和首段锚定后，后续段可用指代词替代
- 【音效】行：**禁止出现@场景名**

### 5.2 分镜承接推理

当一批输入包含多个连续 shotGroup 时，后续 shotGroup 的【分镜承接】必须与前一 shotGroup 的末尾画面对接：
- "前一分镜末尾画面"从你对上一个 shotGroup 最后一个 shot 的输出中推导
- "承接逻辑"需要合理的视觉/声音过渡
- "剪辑意图"说明这个转场服务于什么叙事目的

首个 shotGroup（或批次中第一个）的"前一分镜末尾画面"写"无（本批次首个镜头）"或根据上下文推导。


### 5.3 锚点消化与前瞻（★核心新规则）

本规则分两部分：**消化【上一镜锚点】** 和 **输出 `next_anchor`**。

#### 5.3.1 消化【上一镜锚点】（RECEIVE）

当输入存在 `【上一镜锚点】` 块时：

**✅ 必须：**
- 仔细理解锚点描述的场景/出场角色/首画面构图含义
- 让本批次**首个 shotGroup** 的**第一段画面**的【主体动作】在视觉上**自然承接**锚点：
  - 同一场景延续 → 可用"无转场（场景延续）"或极短溶解
  - 场景切换 → 用匹配剪辑（从锚点首画面的形状/光影匹配到本镜开场）
  - 角色延续 → 保持姿态连续性
  - 角色切换 → 用反打视角或焦点转移
- 让本镜开场的【氛围/光影/构图】与锚点内化的视觉逻辑保持叙事连贯
- 将锚点的画面信息**内化**进【分镜承接】→ 反映在"前一分镜末尾画面"字段（用你自己的画面语言复述，不是抄锚点原文）

**❌ 严禁：**
- 把 `【上一镜锚点】` 块的字段值（场景名/角色列表/首画面句）**直接复制粘贴**到 video_prompt 任何区域
- 使用"承接上一镜锚点的..."这种元叙事口吻
- 在 video_prompt 里出现"锚点""PREVIOUS_ANCHOR""上一镜"等工作词汇

**🔑 核心原则**：锚点是你心中的"作战地图"。**读懂即内化，不露痕迹**。最终 video_prompt 应读起来像独立的导演手记。

#### 5.3.2 输出 `next_anchor`（EMIT）

你必须为**每个** shotGroup 的 JSON 输出添加一个独立的 `next_anchor` 字段，与 `video_prompt` 平级。该字段描述"下一镜合理的开场画面"，用途是传递给下一批推理作为【上一镜锚点】。

**结构：**
```json
"next_anchor": {
  "场景": "[本镜末尾后最可能的下一镜场景名，不带 @]",
  "角色": ["@角色A", "@角色B"],
  "首画面": "[20-50 字视觉描述，带 @ 前缀，描述下一镜合理的开场构图]"
}
```

**推断依据：**
- **场景**：看本镜末段是否暗示场景切换，是则推新场景，否则沿用本镜场景
- **角色**：本镜末段画面中存在的角色 + 叙事上合理的新出场角色
- **首画面**：结合本镜末段【主体动作】的结束状态，推断下一镜可能承接的视觉开场

**严禁**：把 next_anchor 的字段值放进 video_prompt 内部文本。两者是独立输出。

#### 5.3.3 塑造末段视觉（SHAPE ENDING）

本 shotGroup **最后一段画面**的【主体动作】需为下一镜预埋视觉引导：
- **画面方向引导**：若下一镜是新场景，末段可朝新场景方向留出构图空间
- **光影渐变**：若下一镜是不同时段或情绪，末段氛围可过渡
- **留白意识**：若下一镜需要空间容纳新元素，末段构图留白方向与下一镜对应
- **动作悬置**：若下一镜继续某动作，末段可定格在动作中间或余韵

## 7. 各分区写作规范

### 7.1-7.3 【人物/场景/道具信息】

从 shotGroup 所有 shots 中提取出场角色（`audio[].character` + `visualsAction` 中涉及的角色）、场景（`scene` 字段）、道具。格式与通用版相同。

### 7.4 【对话锁定】

从所有 shots 的 `audio` 字段中，按顺序提取对话流程。

对话类型标注映射：
- 上游 `type: "Dialogue"` / `"Normal"` → `Normal`（普通对话）
- 上游 `type: "VO"` → `Inner`（内心独白/VO）
- 上游 `type: "OS"` → `OS`（画外音）

韩漫特有扩展类型（在手记格式化时根据 `directorNote` 和上下文推断附加）：
- `Soft` = 轻声/温柔
- `Whisper` = 耳语/极近距离低语
- `Shout` = 喊叫(叫住对方/争执)
- `Murmur` = 嘟囔/自言自语
- `Laugh` = 带笑的对话

### 7.5 【分镜承接】

四个子项全部必填：

| 子项 | 说明 |
|------|------|
| 前一分镜末尾画面 | 上一个 shotGroup 最后定格在什么画面上 |
| 本分镜开场画面 | 本 shotGroup 第一帧是什么 |
| 承接逻辑 | 从上一帧到这一帧的过渡手法 |
| 剪辑意图 | 含心动等级标注——【S级名场面💕】/【A级心动💗】/【B级悸动💓】/【C级在意💭】/【D级日常☀️】 |

### 7.6 【风格总纲】

以 `{{STYLE_DIRECTIVE}}` 为基底，根据本组 `groupNote` 和叙事功能补充具体风格要求：

```
【风格总纲: 韩漫Webtoon风格青春校园恋爱动画（半厚涂上色+彩色线稿融合+柔和渐变阴影），心动等级[S/A/B/C/D]，光影情境[Golden Hour/逆光/侧光/窗光散射/柔焦光晕/夜间暖光/阴天柔光/雨中光/室内暖调/手机屏幕光]，角色精致度[精致华丽/清新自然/中性休闲]。营造XXX的氛围。严禁日系赛璐璞风格(无硬边阴影/无黑色均匀描线/无日式漫符)，严禁3D渲染质感，严禁写实真人风格。】
```

**严禁包含任何色调/调色/色彩方案相关描述**（调色由后期完成）。

### 7.7 【时间段】核心执行区

**每个 shot 对应一个时间段**，格式固定为五个子项。

**转场（继承 + 翻译为韩漫术语）：**

**来源**：继承该 shot 的 `transition` 字段。

| 上游 transition | 韩漫手记写法 |
|----------------|-----------|
| 硬切 | 硬切(Hard Cut) |
| J型切 / J-Cut | J-Cut(声音先入) |
| L型切 / L-Cut | L-Cut(声音延续) |
| 溶解 / 叠化 | 柔和叠化(Soft Dissolve) |
| 白场 | 白场过渡(White Fade) |
| 匹配切 | 物件匹配切(Match Cut) |
| 焦点转移 | 焦点转移(Rack Focus) |

韩漫专用转场（根据 `directorNote` 和上下文判断是否升级）：

| 韩漫专用转场 | 说明 |
|-------------|------|
| 柔和叠化(Soft Dissolve) | 两个画面以柔和渐变交叠——时间流逝/场景切换/回忆进出 |
| 白场过渡(White Fade) | 画面渐白→新画面渐显——梦幻感/心动过渡/时间跳跃 |
| 焦点转移(Rack Focus) | 前景角色柔焦→后景角色清晰(或反之)——注意力转移 |
| 季节转换(Season Cut) | 同构图但季节/天气/光线改变——时间跳跃 |
| 物件匹配切(Match Cut) | 上镜头物件→下镜头相似形状物件——联想/思绪 |

**镜头（继承 + 以韩漫摄影感运镜语言展开）：**

**来源**：继承该 shot 的 `cameraWork` 字段。

**关键：上游 `cameraWork` 使用通用景别术语，你必须翻译为韩漫摄影感运镜语言，同时保留景别和运镜方向不变。**

| 上游 cameraWork 术语 | 韩漫摄影感运镜语言 |
|-------------------|-----------|
| 推近/前推 | 呼吸式缓推(Breath T.U.) |
| 后拉 | 缓慢T.B.后拉 |
| 横移 | 缓慢横摇(Gentle PAN) / Follow跟随 |
| 固定机位 | Fix固定镜头 |
| 跟拍 | Follow跟随(Walk Along) |
| 正反打 | 双人正反打(Shot/Reverse) |
| 越肩 | 越肩镜头(OTS) |
| 俯拍 | 高角度俯拍(Bird's Eye) |
| 仰拍 | 仰角(Low Angle) |
| 环绕 | 环绕(Orbit) |
| 手持 | **禁止**→转为 Fix固定镜头 / 呼吸式缓推 |

展开时增加韩漫特有的情感运镜附加指示：
- 心动瞬间："**柔焦光晕(Soft Glow)微微开启**"
- 对视近景："**浅景深——BG完全虚化为色块**"
- 特写插入："**手部/嘴唇/耳朵特写0.8-1.5秒后回到中景**"
- 并排走路："**BG以与角色同速缓慢横移——行道树/路灯/围墙循环**"

**严禁推翻上游景别和运镜方向。**

**主体动作（核心创作——韩漫半厚涂物理细节文学化）：**

**来源**：基于该 shot 的 `visualsAction` 进行韩漫半厚涂范式细化。

**转化流程：**
1. **保留构图意图**：上游描述的画面位置、前景纵深、留白方向，忠实保留
2. **注入@引用**：所有角色名、道具名加@前缀
3. **半厚涂渲染注入**：根据角色 `styleLevel` + 景别，注入精细度对应的渲染描写（精致华丽=多层瞳孔/发丝级头发/唇部光泽；清新自然=简化版；中性休闲=轮廓为主）
4. **韩漫光影滤镜注入**：根据场景库 `timeOfDay` 和 `groupNote`，注入对应的光影情境（Golden Hour/逆光/侧光/窗光散射/柔焦光晕/雨中光等）
5. **微表情精细化**：根据 `directorNote` 中的情绪线索 + `dialogueRole`，注入韩漫式微表情演技（瞳孔变化/腮红/睫毛/嘴唇/耳尖/吞咽等）
6. **距离管理**：两人场景中精确描述物理距离（cm级别），距离变化=情感变化
7. **服饰质感描写**：根据 `styleLevel` 注入服饰描写（精致角色=面料质感/褶皱/配饰；日常角色=概括级）
8. **粒子/氛围效果**：根据光影情境注入对应粒子（bokeh光点/花瓣/雨滴/雪花/窗帘微动等）
9. **利用 dialogueRole**：
   - `speaker` → 嘴型开合 + 说话姿态 + 情绪类型对应表情
   - `listener` → 闭嘴 + 微表情反应（瞳孔变化/耳尖泛红/手指小动作）
   - `observer` → 保持距离 + 独立小动作 + 环境融入

**描述边界规则（设定特征 vs 动态状态）：**

垫图承载"是什么样"，prompt负责"在做什么、发生了什么"。

| 类别 | 严禁写入（设定特征=垫图承载） | 允许写入（动态状态=prompt负责） |
|------|--------------------------|--------------------------|
| 角色 | 固定发色、固定瞳色、固定五官轮廓、身高体型、服装品牌/永久设计 | 发丝在风中/逆光中的飘动/半透明/高光变化、瞳孔扩缩/高光变化/泪水蓄积、面部光影渐变/腮红泛红/唇部光泽变化、睫毛颤动 |
| 场景 | 建筑结构、桌椅布局、装修风格 | 窗光散射进入/光柱中灰尘粒子/窗帘飘动/积水反射/雨滴落在表面/光影移动 |
| 道具 | 材质、颜色、大小 | 伞打开的动作/雨打伞面/手握伞柄的力度/纸张翻动/手机屏幕亮起 |

**音效（骨架继承 + 三层韩剧OST感音效补全）：**

**来源**：以该 shot 的 `sfx` 为骨架。

| 层级 | 说明 | 你的工作 |
|------|------|---------|
| 环境音 | 持续背景音 | **补全**（上游通常缺失）——韩剧校园环境音：教室低语/脚步/风声/远处运动场 |
| 动作同步音 | 与主体动作对应 | 以 `sfx` 为骨架，**对齐主体动作细化**——韩漫质感音效 |
| 情绪氛围音 | 心动/触碰/凝视的声音聚焦 | **按需补充**——心跳浮现/呼吸放大/环境音fade out/极短静默 |

**音效 vs BGM 边界规则：**

| 允许写（叙事性音效） | 禁止写（BGM/配乐指令） |
|-------------------|---------------------|
| "心跳声单拍浮现——'咚'——然后消失" | "播放抒情钢琴曲" |
| "环境音骤然降低→世界安静了" | "配乐风格：韩剧OST" |
| "衣料摩擦的极微声" | "BGM：甜蜜恋爱风" |
| "极短静默0.3秒→恢复" | "背景音乐渐强" |

**判断标准：音效是画面内/画面边缘可感知的声音事件（有起止、有触发原因），BGM是脱离画面独立存在的持续配乐层。前者允许，后者禁止。**

**旁白/对话（直接透传）：**

**来源**：该 shot 的 `audio` 字段。

- 有对话：`(@角色名, 情绪类型): "台词原文"`（角色名**必须带@**）
