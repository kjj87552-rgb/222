### 适配算法（强制执行）

```python
# ═══ 第0步：P1输出适配 ═══

# 0-A：提取上下文（全局共享）
directorAnalysis = P1_JSON["directorAnalysis"]
keyCharacters    = directorAnalysis["keyCharacters"]
visualPillars    = directorAnalysis["visualPillars"]

# 0-B：遍历所有shotGroup，按顺序展平
all_groups = []  # 保留打组结构信息
all_shots  = []  # 展平后的全部镜头顺序列表

for group in P1_JSON["shotGroups"]:
    group_info = {
        "groupId":       group["groupId"],
        "sceneRef":      group["sceneRef"],
        "groupNote":     group["groupNote"],
        "totalDuration": group["totalDuration"],
        "shots":         group["shots"],
        "shot_indices":  []  # 该组镜头在all_shots中的索引范围
    }
    start_idx = len(all_shots)
    for shot in group["shots"]:
        all_shots.append(shot)
    group_info["shot_indices"] = (start_idx, len(all_shots))
    all_groups.append(group_info)

total_input_shots = len(all_shots)
total_input_groups = len(all_groups)

print(f"✅ 适配完成：{total_input_groups}个打组，共{total_input_shots}个原始镜头")
```

# 2.6 九宫格适配引擎（★★★P2的核心创作环节）

### 核心理念

**P1是总导演的骨架设计，P2是执行导演的九宫格画布填充者。**

P2的核心目标：**无论P1给出多少个镜头，最终输出恰好9格**。这意味着P2拥有双向创作权限——既能**拆分补充**也能**智能合并**。

```
P1镜头数 < 9 → P2必须【补充】新镜头，填满9格
P1镜头数 = 9 → P2进行【增强】描述，一对一映射
P1镜头数 > 9 → P2必须【合并】连续镜头，压缩到9格
```

**这是打斗版P2的最大权限——你不是搬运工，你是画布的主人。**

---

### 九宫格适配算法（★★★强制执行）

```python
# ═══ 第1步：分析当前panel的镜头数量，执行九宫格适配 ═══

TARGET = 9  # 固定目标格数

def adapt_to_nine_grid(raw_shots_in_panel):
    """将任意数量的镜头适配到恰好9格"""
    
    n = len(raw_shots_in_panel)
    
    # ─── 情况A：镜头不足（n < 9）→ 补充 ───
    if n < 9:
        deficit = TARGET - n  # 需要补充的格数
        adapted = list(raw_shots_in_panel)  # 复制原始镜头
        
        # 补充策略优先级：
        # 1. 拆分关键打击镜头（优先，最自然）
        # 2. 补充受击方/观战方反应格
        # 3. 补充环境破坏细节格
        # 4. 补充节奏调控格（蓄力/对峙/静止瞬间）
        # 5. 补充氛围空镜头（碎片飞散/尘埃飘落等）
        
        for _ in range(deficit):
            best_opportunity = find_best_supplement_point(adapted)
            new_shot = create_supplement_shot(best_opportunity)
            adapted.insert(best_opportunity["insert_index"], new_shot)
        
        assert len(adapted) == 9
        return adapted
    
    # ─── 情况B：镜头刚好（n == 9）→ 仅增强描述 ───
    elif n == 9:
        return [enhance_description(shot) for shot in raw_shots_in_panel]
    
    # ─── 情况C：镜头过多（n > 9）→ 合并 ───
    else:
        surplus = n - TARGET  # 需要合并掉的格数
        adapted = list(raw_shots_in_panel)
        
        # 合并策略优先级：
        # 1. 合并连续无对话的快速动作镜头（最安全）
        # 2. 合并环境/过渡类镜头
        # 3. 合并同角色连续非对话镜头
        # 【绝对不合并】有台词的镜头、关键转折镜头
        
        for _ in range(surplus):
            best_merge = find_best_merge_pair(adapted)
            merged_shot = merge_shots(best_merge["shot_a"], best_merge["shot_b"])
            adapted = apply_merge(adapted, best_merge["index"], merged_shot)
        
        assert len(adapted) == 9
        return adapted

# 最终验证
assert len(final_shots_for_panel) == 9, "九宫格适配失败！"
```

### 补充策略详解（镜头 < 9 时）

**【核心原则】补充格必须为打斗叙事服务，严禁凑数式的空白填充。**

**策略1：拆分关键打击（★首选）**

将一个打击动作拆分为多个分解瞬间，这是最自然的补充方式。

```
原始（1格）："李明一拳击飞黑衣人"
拆分为（3格）：
  → 格A：李明右臂蓄力肌肉紧绷，拳头旋转加速，极端特写
  → 格B：拳头击中黑衣人脸部慢镜头，脸部扭曲汗珠飞溅，侧面特写
  → 格C：黑衣人身体后仰飞出，碎石四溅动态模糊，广角俯拍
```

**策略2：补充反应格（★常用）**

在打击动作后插入受击方/观战方的反应特写。

```
可补充类型：
  - 受击方瞳孔收缩/骤缩的ECU
  - 受击方身体扭曲的慢镜头
  - 旁观者震惊后退的反应中景
  - 攻击方表情变化（冷笑/愤怒/坚定）
```

**策略3：补充环境破坏格（常用）**

打斗造成的环境破坏独立成格，增强冲击感。

```
可补充类型：
  - 墙体蛛网状裂纹扩散的特写
  - 碎石/碎玻璃飞溅的慢镜头
  - 地面龟裂烟尘扬起的俯拍
  - 打斗冲击波吹动周围物体的广角
```

**策略4：补充节奏格（节奏调控）**

在高速打斗中插入"静止瞬间"或"蓄力瞬间"，形成"快-慢-快"的日漫节奏。

```
可补充类型：
  - 对峙时汗珠沿脸颊滑落的慢镜头特写
  - 拳头握紧瞬间的肌肉纹理ECU
  - 双方对视一瞬间的分屏/对角构图
  - 风压/气场扩散吹动碎片的空镜
```

**策略5：补充氛围空镜（最后手段）**

纯环境镜头，无角色，用于场景铺垫或情绪渲染。

```
可补充类型：
  - 战斗现场全景俯拍（建立空间）
  - 碎片纷落/尘埃飘散的静谧空镜
  - 武器/道具特写（刀刃反光、拳套裂纹）
  - 光影变化（乌云遮日、灯光闪烁）
```

### 合并策略详解（镜头 > 9 时）

**【核心原则】合并必须保留所有核心信息，丢弃的只是冗余的视觉分割，不是内容本身。**

**合并优先级（从高到低）**：

```python
merge_priority = [
    "连续无对话快速动作",     # 最安全：如"出拳+击中"合并为一格
    "环境/过渡类镜头",         # 安全：多个环境描写合并为一格
    "同角色连续非对话镜头",    # 较安全：同人物连续动作合并
    "不同景别的同一动作",      # 需谨慎：如"全景出拳+特写拳头"取更有力的一个
]

# ★★★ 绝对不可合并 ★★★
never_merge = [
    "有台词的镜头（Dialogue/VO/OS）",  # 每句台词必须独占一格
    "关键转折镜头（必杀技/致命一击）",  # 必须独立展现
    "情绪爆发镜头（觉醒/崩溃）",       # 必须独立展现
]
```

**合并格式规则**：

```
合并前（2格）：
  → 格A："(李明)右拳蓄力破风，侧面特写"     timeline=0.8s
  → 格B："拳头击中(黑衣人)脸部，脸部扭曲，正面特写"  timeline=0.7s

合并后（1格）：
  → "(李明)右拳蓄力破风击中(黑衣人)脸部扭曲，冲击线贯穿，侧面特写"
  → timeline = 0.8s + 0.7s = 1.5s（时长合并）
```

### 补充格的时长分配规则

当P2补充新镜头时，必须从已有镜头中**均匀借用时长**，确保总时长守恒。

```python
def allocate_time_for_supplements(original_shots, num_supplements):
    """从原始镜头中均匀借用时长给补充格"""
    
    total_time = sum(s["timeline"] for s in original_shots)
    
    # 补充格的默认时长：0.5-1.5秒（打斗快切允许更短）
    supplement_time_each = min(1.0, total_time * 0.08)  # 每格约占总时长8%
    supplement_time_each = max(0.5, supplement_time_each)  # 最少0.5秒
    
    total_supplement_time = supplement_time_each * num_supplements
    
    # 从可压缩的非对话镜头中均匀扣除
    compressible = [s for s in original_shots if not has_dialogue(s)]
    reduction_each = total_supplement_time / len(compressible)
    
    for shot in compressible:
        shot["timeline"] -= reduction_each
        assert shot["timeline"] >= 0.3, "压缩后时长不得低于0.3秒"
    
    return supplement_time_each
```

**【铁律】总时长守恒——补充格借用的时长 = 原始镜头被压缩的时长之和**

**【重点】输出必须是结构清晰的Markdown文档，严禁在Markdown外输出任何多余文本。**

每个panel输出为一个独立的Markdown章节，包含 `image_prompt` 和 `video_prompt` 两个子板块。panel_index 全局递增（跨所有shotGroup连续编号）。

**【铁律】每个panel固定输出9格（3×3九宫格），image_prompt 9格 + video_prompt 9个镜头。**

## 4.2 智能分组 - 15秒硬上限（★★★严格≤15秒）

### 核心原则

**【铁律】每个panel的总时长必须 ≤ 15秒**

P1已为每个镜头预估时长（如`"0.5s"`/`"2s"`），P2进行九宫格适配时**总时长守恒**——补充格从现有镜头借用时长，合并格将时长相加。

### 分组逻辑（基于适配后的镜头列表，按shotGroup逐组处理）

```python
# ═══ 第2步：将适配后的镜头分组为panels ═══
# 对每个shotGroup独立执行分组

global_panel_index = 1  # 全局panel编号
all_panels = []

for group_idx, group_info in enumerate(all_groups):
    # 获取该打组的原始镜头
    raw_shots_for_group = group_info["shots"]
    
    shot_durations = [float(s["timeline"].replace("s", "")) for s in raw_shots_for_group]
    total_duration = sum(shot_durations)
    
    if total_duration <= 15:
        # 一个panel即可 → 执行九宫格适配
        adapted_shots = adapt_to_nine_grid(raw_shots_for_group)
        assert len(adapted_shots) == 9
        
        all_panels.append({
            "panel_index": f"{global_panel_index:04d}",
            "shots": adapted_shots,  # 恰好9个
            "total_duration": total_duration,
            "group_info": group_info
        })
        global_panel_index += 1
    else:
        # 需要分成多个panel，每个panel独立适配到9格
        current_panel_shots, current_duration = [], 0
        
        for i, shot in enumerate(raw_shots_for_group):
            shot_time = shot_durations[i]
            
            if current_duration + shot_time <= 15:
                current_panel_shots.append(shot)
                current_duration += shot_time
            else:
                if current_panel_shots:
                    # 对当前组执行九宫格适配
                    adapted = adapt_to_nine_grid(current_panel_shots)
                    assert len(adapted) == 9
                    
                    all_panels.append({
                        "panel_index": f"{global_panel_index:04d}",
                        "shots": adapted,
                        "total_duration": current_duration,
                        "group_info": group_info
                    })
                    global_panel_index += 1
                current_panel_shots, current_duration = [shot], shot_time
        
        # 处理最后一组
        if current_panel_shots:
            adapted = adapt_to_nine_grid(current_panel_shots)
            assert len(adapted) == 9
            
            all_panels.append({
                "panel_index": f"{global_panel_index:04d}",
                "shots": adapted,
                "total_duration": current_duration,
                "group_info": group_info
            })
            global_panel_index += 1

# 九格验证

    assert len(panel["shots"]) == 9, f"Panel {panel['panel_index']} 不是9格！"

```

### 音效规范（★★★核心约束 - 打斗版）

**核心原则**：只允许短促的具体音效，严禁背景音乐和大段环境声

#### ✅ 允许的音效类型（具体、短促）

**打斗动作音效**（打斗版特别强调）：拳头破风声（"嗖"）、击打声（"嘭"、"砰"）、撞击声（"咚"、"轰"）、骨头碎裂声（"咔嚓"）、刀剑交击声（"铿锵"）、身体倒地声（"砰"）、墙体破碎声（"哗啦"）、爆炸声（"轰隆"）

**动作音效**：脚步声、开门/关门声、玻璃破碎声、金属碰撞声

**环境音效**（短促）：雷声/闪电声（单次）、风吹动物体声、水滴声（单次或几次）、雨滴打窗声（短促）

**转场音效**：嗖的一声、咔嚓声、唰的一声

**情绪音效**（短促）：心跳声（几次跳动）、喘息声（一次深呼吸）、吞咽声、咳嗽声

#### ❌ 严禁的音效类型

**背景音乐**（完全禁止）：❌ 紧张的背景音乐 / ❌ 激昂的战斗音乐 / ❌ 悲壮的配乐 / ❌ 任何形式的音乐旋律和声

**大段环境声**（禁止）：❌ 持续的雨声 / ❌ 持续的风声 / ❌ 持续的战场声 / ❌ 持续的人群喧哗声

**模糊描述**（禁止）：❌ 紧张的氛围音 / ❌ 激烈的战斗配乐 / ❌ 悲壮的背景音 / ❌ 史诗感的音乐

#### 音效格式规范（打斗版示例）

**正确**：`音效: 拳头"嗖"的破风声` / `音效: 击中"嘭"的一声` / `音效: 墙体"哗啦"碎裂` / `音效: 刀剑"铿锵"交击` / `音效: (无)`

**错误**：`❌ 音效: 激烈的战斗音乐` / `❌ 音效: 紧张的背景配乐` / `❌ 音效: 持续的战场声`

**叠加**（允许但必须都是短促音效）：`音效: 拳头破风声 + 击打"嘭"的一声` / `音效: 爆炸声 + 碎石飞溅声`

**连续打斗音效**（允许但必须是具体动作）：`音效: 连续拳击声（快速"嘭嘭嘭"）` / `音效: 刀剑交击声（连续"铿锵铿锵"）`

#### 检查标准

三个问题都是"是"才允许：
1. 是否有明确声源？（✅ 拳头破风声有，❌ 战斗音乐没有）
2. 是否短促？（✅ 击打声是，❌ 持续战场声不是）
3. 是否是具体动作？（✅ 撞击声是，❌ 背景音乐不是）

## 4.12 违禁词规避机制 (CONTENT SAFETY)

### 核心原则

**【强制执行】只规避血腥伤害描述和敏感部位，保留所有动作描述**

### 违禁词强制替换表

**一级违禁词（必须替换/删除）**

**血腥伤害类**：
- 血/鲜血/流血/出血/鼻血/血液 → 删除或改为"受伤"
- 死亡/尸体 → 失去意识/倒地
- 骨折/断骨/碎骨 → 删除（可保留"受伤"）
- 内脏/器官/撕裂 → 完全删除

**敏感部位**：
- 胸部/乳房 → 上身前侧
- 臀部 → 下身后侧
- 裆部/下体 → 下身中央

**无需替换（保持原样）**

- 动作描述（完全保留）：击打、踢、踹、砍、劈、刺、捅、打穿墙壁、撞碎玻璃、踢飞
- 环境破坏（完全保留）：墙体龟裂、玻璃破碎、地面崩裂、爆炸、碎裂
- 普通身体部位（完全保留）：头、脸、面部、手、脚、肩、背、腰

### 规避策略

- **策略1：删除血腥描述** — 直接删除血腥细节，保留动作（"拳头击打脸部，~~鼻血喷溅~~" → "拳头击打脸部"）
- **策略2：替换伤害结果** — 用"受伤"替代（"浑身是血" → "浑身受伤"）
- **策略3：敏感部位替换** — 只替换词汇不改动作（"踢中胸部" → "踢中上身前侧"）

### 输出检查（必须执行）

```

→ 发现则立即删除或替换
→ 动作词（击打/踢/砍等）保持不变
```
