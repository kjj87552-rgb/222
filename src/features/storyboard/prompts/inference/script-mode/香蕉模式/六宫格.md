# 3. 六格重构引擎（★★★核心——P2的灵魂）

## 3.1 核心理念

**无论P1给多少个镜头，P2的输出永远是固定6格（2×3布局）。**

这不是简单的凑数——而是执行导演对素材的**二次剪辑**。你要像剪辑师一样思考：哪些镜头是叙事脊柱必须保留？哪些可以合并成一格的信息密度？哪里缺了一个呼吸的空镜？哪个情绪节点值得拆出特写？

## 3.2 通读分析（★★★先读后写，禁止边读边写）

**【铁律】拿到一个shotGroup后，必须先完整通读所有镜头，理解全貌，再制定六格策略。严禁逐镜头处理。**

通读时回答以下问题：

```
1. 叙事弧线：这组镜头讲了什么？起承转合在哪？
2. 情绪走向：情绪从哪里到哪里？高潮点在第几个镜头？
3. 对话分布：有几句台词？哪些是关键台词、哪些是反应性短句？
4. 景别节奏：P1的景别序列是什么？有没有连续重复？
5. 视觉重心：哪个镜头最有画面冲击力？哪个最平淡？
6. 缺口识别：缺环境建立？缺反应特写？缺情绪留白？缺过渡？
```

## 3.3 六格策略（N个镜头 → 6格的映射决策）

通读完成后，根据镜头数量和叙事结构，选择映射策略：

### 情况A：P1镜头数 < 6（需要补充）

```
P1给了N个镜头（N < 6），需要补充 6-N 个格子。
```

**补充优先级**（按价值从高到低）：

| 优先级 | 补充类型 | 触发条件 | 示例 |
|--------|----------|----------|------|
| ★★★ | **情绪特写拆分** | P1有高情绪镜头但只给了一个中景 | 将"他震惊地看着信"拆为：①信件内容特写 ②瞳孔收缩极特写 |
| ★★☆ | **环境建立镜头** | 该组缺少空间交代 | 补充一格：走廊尽头的光影、窗外的城市夜景 |
| ★★☆ | **listener反应格** | 对话密集但缺少反应 | 对话间插入：听者的微表情特写 |
| ★☆☆ | **氛围空镜** | 情绪转折处缺少呼吸 | 补充：风吹动窗帘、雨滴滑落玻璃、烟灰坠落 |
| ★☆☆ | **细节插入格** | 叙事线索需要视觉锚点 | 补充：桌上的照片、手中攥紧的钥匙、墙上的时钟 |

**补充原则**：
- 补充的格子必须服务于现有叙事，不能添加P1未涉及的新剧情
- 补充格通常是observer类型（无对话），用于呼吸感和视觉层次
- 补充格的时长从现有镜头中匀出，或使用1-2秒短镜头

### 情况B：P1镜头数 = 6（一对一精修）

```
P1恰好给了6个镜头 → 理想情况，一对一映射。
```

P2的工作集中在**每格的质量提升**：
- 增强visualsAction描述（补充微表情、光影互动、构图细节）
- 优化景别递进（避免连续相同景别）
- 细化转场关系

### 情况C：P1镜头数 > 6（需要合并）

```
P1给了N个镜头（N > 6），需要将N个镜头压缩到6格。
```

**合并策略**（按优先级）：

| 优先级 | 合并类型 | 条件 | 做法 |
|--------|----------|------|------|
| ★★★ | **连续快切合并** | 多个<1.5秒的快速镜头 | 合并为一格，用"跳切""蒙太奇"风格融合 |
| ★★☆ | **同景别对话合并** | 连续2个相同景别的对话 | 合为一格，采用分割构图或对比构图 |
| ★★☆ | **动作序列合并** | 连续动作的多个步骤 | 合为一格，选取动作高潮瞬间 |
| ★☆☆ | **环境+动作合并** | 环境建立镜头紧跟角色动作 | 合为一格，角色置于环境中 |

**合并铁律**：
- **对话不可丢弃**：所有Dialogue/VO/OS台词必须在6格中找到归属，一句都不能少
- **叙事顺序不可打乱**：合并只是压缩，不能重排
- **每格最多承载2句台词**（仅限合并场景下，优先仍是每格1句）

### 情况D：P1镜头数 >> 6（大量镜头，深度裁剪）

```
P1给了10+个镜头 → 需要大胆裁剪，抓住叙事脊柱。
```

**裁剪思路**：
1. 标记**叙事脊柱镜头**（推动剧情的关键镜头）→ 必须保留
2. 标记**情绪锚点镜头**（高潮、转折）→ 优先保留
3. 标记**可牺牲镜头**（过渡、重复、冗余反应）→ 合并或吸收
4. 将保留的镜头映射到6格，必要时合并相邻镜头

**裁剪后自检**：
- 所有对话是否都被保留？
- 叙事是否仍然连贯？（观众能看懂）
- 6格之间是否有起承转合的节奏感？

## 3.4 六格节奏模板（参考，非强制）

以下是常见的6格节奏结构，P2可灵活参考：

**模板A：经典叙事弧**
```
格1：环境建立（远景/全景，交代空间）
格2：角色引入（中景，角色登场/动作）
格3：对话/冲突展开（中特写，speaker）
格4：反应/升级（特写，listener反应或情绪升级）
格5：高潮/转折（特写/极特写，情绪顶点）
格6：余韵/留白（空镜/远景，情绪沉淀）
```

**模板B：对话密集型**
```
格1：空间交代（中景，双人关系构图）
格2：speaker A（中特写+台词）
格3：speaker B 反击（中特写+台词）
格4：listener反应 / 情绪特写
格5：speaker A 或 B 关键台词（特写+台词）
格6：结局画面 / 隐喻空镜
```

**模板C：动作/情绪爆发型**
```
格1：紧张蓄力（中景，静态构图中的压迫感）
格2：动作触发（中特写，动作起始瞬间）
格3：动作高潮（特写/极特写，冲击力最大的一帧）
格4：反应/后果（对方的反应或环境破坏）
格5：情绪延续（特写，表情/呼吸/微动作）
格6：收束/过渡（远景或细节空镜）
```

**【注意】模板仅供参考，P2应根据实际素材灵活调整，不要生搬硬套。**

## 3.5 六格构图总则

6格作为一个视觉整体，需要遵循以下构图节奏：

- **景别递进**：严禁连续3格以上相同景别。推荐节奏如 WS→MS→CU→MCU→ECU→WS 或类似波浪式
- **视线引导**：格与格之间的角色目光方向、动作方向应形成视觉流动
- **疏密交替**：信息密度高的格（对话+动作）与呼吸格（空镜/特写）交替
- **首尾呼应**：第1格（入口）和第6格（出口）构成视觉书挡，建议一开一合（如远景开→特写收，或特写开→远景收）

# 5. 各板块生成规则

## 5.1 image_prompt 规则

### 固定声明

每个panel的image_prompt开头固定写：

```
请帮我生成一张2×3的6格彩色分镜漫画图并且每个分镜都有序号编号。
```

### 每格格式

```
【第X格 序号X】【场景名】(角色A)(角色B)互动动作，场景细节，构图方式。
对话：(角色名): "台词内容"
```

### 描述要素

**视觉描述必含**：(角色名) + 核心动作/表情 + 互动关系（多人）+ 场景细节 + 构图方式 + 色调氛围

**视觉描述控制在30-50字**，精炼有力，禁止冗余。

### 对话规则

**✅ 必须写入的类型**：
- **Dialogue**："你在说什么？"
- **VO（内心独白）**："我不能失败..."
- **OS（旁白）**："就在那一刻，命运的齿轮开始转动"

**❌ 严禁写入的类型**：
- 音效类："呼…呼…" / "啊！" / "咳咳"
- 环境声：脚步声/心跳声/雨声

**判断标准**：能否用字幕显示且观众能理解意思？能→写入，不能→只放video_prompt音效字段。

**格式**：有对话时在视觉描述后换行 `对话：(角色名): "台词"`，无则省略。

### characters字段

- 有具名角色出场：列出角色名
- 纯空镜：characters为空

### 空镜头格

无角色标注，不写characters，通常无对话。用于环境渲染、情绪留白、道具特写。

---

## 5.2 video_prompt 规则

### 核心约束

**video_prompt必须有恰好6个【镜头X】，与image_prompt的6格严格一一对应。**

### 各板块说明

**【人物信息】**：提取当前panel所有具名角色，每行一个用()包裹。纯环境panel可省略。

**【对话锁定】**：遍历audio字段按时间序提取，格式 `角色A(类型) → 角色B(类型)`。

**【场景分析】**：
- 场景：从P1的scene字段提取
- 承接：首panel写"开场"，后续说明衔接
- 过渡：场景切换说明，连续场景写"场景不变"

**【分镜承接】**：

```python
if panel_index == "0001":
    前一分镜末尾画面: "无（本片段为开场）"
    本分镜开场画面: [第1格的画面核心]
    承接逻辑: "首个镜头，从[景别/动作]开始"
    剪辑意图: [开场设计意图]
else:
    前一分镜末尾画面: [上一panel第6格的画面]
    本分镜开场画面: [当前panel第1格的画面]
    承接逻辑: [视觉连续/跳跃/情绪对比/时空跳跃]
    剪辑意图: [流畅性/冲击力/对比性/节奏性]
```

**避免**：❌"自然过渡"❌"推动剧情"这类空话。要写具体的视觉关系。

**【风格总纲】**：首panel从`visualPillars`提取风格，后续panel从directorNote/groupNote提取情绪。标注"严禁写实真人，必须动漫化"。

### 镜头格式

```
【镜头X】
转场: [转场类型] - [与前一镜头的视觉关系简述]
镜头: [纯镜头运动描述：景别、角度、运镜方式]
主体动作: [角色的动作/表情/状态，含微动作]
音效: [具体短促音效] 或 (无)
旁白/对话: (角色名, 语气): "台词" 或 (无)
```

### 镜头1转场规则

# 6. 时长规则

## 6.2 时长分配参考

|----------|----------|

## 6.3 对话时长铁律

**对话格的时长 = P1原始timeline，不可压缩。**

- 优先压缩非对话格（每格最多压缩0.5秒，不低于0.5秒）
- 总压缩量不超过2秒
- 如果仍超时 → 该打组必须拆为2个panel（各6格），按叙事断点分割
