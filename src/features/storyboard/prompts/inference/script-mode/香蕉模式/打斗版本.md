# 2.5 P1输出适配（★强制首步）

### 核心功能

从P1的JSON中提取**所有打组**的镜头序列与上下文信息，按顺序展平为完整的工作素材。

### 适配算法（强制执行）

```python
# ═══ 第0步：P1输出适配 ═══

# 0-A：提取上下文（全局共享）
directorAnalysis = P1_JSON["directorAnalysis"]
keyCharacters    = directorAnalysis["keyCharacters"]
visualPillars    = directorAnalysis["visualPillars"]

# 0-B：遍历所有shotGroup，按顺序展平
all_groups = []  # 保留打组结构信息
all_shots  = []  # 展平后的全部镜头顺序列表

for group in P1_JSON["shotGroups"]:
    group_info = {
        "groupId":       group["groupId"],
        "sceneRef":      group["sceneRef"],
        "groupNote":     group["groupNote"],
        "totalDuration": group["totalDuration"],
        "shots":         group["shots"],
        "shot_indices":  []  # 该组镜头在all_shots中的索引范围
    }
    start_idx = len(all_shots)
    for shot in group["shots"]:
        all_shots.append(shot)
    group_info["shot_indices"] = (start_idx, len(all_shots))
    all_groups.append(group_info)

total_input_shots = len(all_shots)
total_input_groups = len(all_groups)

print(f"✅ 适配完成：{total_input_groups}个打组，共{total_input_shots}个原始镜头")
```

# 2.6 分镜细化引擎（★★★P2的核心创作权限）

### 核心理念

**P1是总导演的骨架设计，P2是执行导演的血肉填充。**

P1受限于宏观规划的粒度，其分镜可能存在以下不足：
- 打斗动作描述偏概括，缺少力量感/冲击感的微动作
- 重要打击瞬间缺少慢镜头特写拆分
- 连续打斗镜头景别单一
- 环境破坏效果描写单薄
- 受击方/观战方反应不够细腻

**P2有权且有责在P1分镜基础上进行艺术细化，但必须遵守权限边界。**

### P2的创作权限

**✅ 允许（细化增强）**：

| 操作 | 说明 | 示例 |
|------|------|------|
| **拆分镜头** | 将P1的一个粗粒度镜头拆为2-3个更精细的镜头 | P1"他一拳击飞对手"→ P2拆为：①蓄力瞬间的拳头特写 ②击中脸部的慢镜头 ③身体后仰飞出的广角 |
| **增强visualsAction** | 补充力量感、冲击效果、微动作细节 | P1"他挥拳攻击"→ P2增强为"右臂肌肉紧绷蓄力，拳头旋转加速破风，冲击线贯穿画面" |
| **景别递进优化** | 打破P1连续相同景别的单调 | P1连续3个中景打斗 → P2调整为 MS→ECU→WS 递进（中景→极端特写→广角） |
| **补充反应细节** | 为受击方/观战方增加具体反应描写 | P1"对手被击退"→ P2"对手瞳孔骤缩，脸部扭曲汗珠飞溅，身体弓形后仰碎石四溅" |
| **环境破坏增强** | 丰富打斗造成的环境破坏层次 | P1"撞击墙壁"→ P2"身体撞入墙体，蛛网状裂纹扩散，碎石烟尘扬起，铁架摇晃" |
| **转场细化** | 将P1的简单转场升级为更有打斗张力的过渡 | P1"硬切"→ P2"快速跳切——从拳头蓄力瞬间切到击中画面，速度线贯穿转场" |

**❌ 严禁（越权操作）**：

| 禁止操作 | 原因 |
|----------|------|
| 修改/删除/截断任何台词（audio.line） | 台词完整性是P0铁律 |
| 删除P1的任何镜头 | 只能增强不能删减 |
| 改变叙事顺序 | 镜头顺序由P1决定 |
| 添加P1未涉及的新角色/新场景 | 超出本打组范围 |
| 改变dialogueRole属性 | speaker/listener由P1定义 |
| 将对话镜头合并 | 一镜一人一句话是P1铁律 |

### 细化判断流程

```python
# ═══ 第1步：逐镜头扫描，识别细化机会 ═══

enhanced_shots = []  # 细化后的镜头列表

for shot in raw_shots:
    opportunities = []
    
    # 检查1：visualsAction是否过于简略？（<30字可能需要增强）
    if len(shot["visualsAction"]) < 30:
        opportunities.append("描述增强")
    
    # 检查2：是否存在概括性打斗描述？
    if 包含概括性描述(shot["visualsAction"]):
        opportunities.append("打斗微动作展开")
    
    # 检查3：关键打击镜头是否需要拆分慢镜头？
    if shot["directorNote"] 暗示关键打击 and shot["timeline"] >= "2s":
        opportunities.append("打击拆分")
    
    # 检查4：连续相同景别？
    if 与前一镜头景别相同 and 与后一镜头景别也相同:
        opportunities.append("景别调整")
    
    # 检查5：受击方反应描写是否单薄？
    if shot["dialogueRole"] == "listener" and visualsAction缺少具体反应:
        opportunities.append("受击反应细化")
    
    # 检查6：环境破坏效果是否单薄？
    if 包含环境破坏 and 描述过于简单:
        opportunities.append("环境破坏增强")
    
    # 执行细化
    if "打击拆分" in opportunities:
        sub_shots = split_shot(shot)
        enhanced_shots.extend(sub_shots)
    else:
        enhanced_shot = enhance_shot(shot, opportunities)
        enhanced_shots.append(enhanced_shot)
```

### 拆分时长规则

当P2将一个P1镜头拆分为多个时：
- **原始时长必须守恒**：拆分后的子镜头时长之和 = P1原始timeline
- **对话镜头不拆分**：有audio的镜头保持完整，只增强描述
- **拆分后每个子镜头至少0.3秒**（打斗版允许更短的快切镜头）

```python
# 示例：P1镜头 timeline="2s", 无对话，关键打击
# P2拆为3个镜头：0.5s(蓄力) + 0.8s(击中慢镜头) + 0.7s(飞出) → 总时长仍为2s
```

## 4.2 智能分组 - 15秒硬上限（★★★严格≤15秒）

### 核心原则

**【铁律】每个panel的总时长必须 ≤ 15秒**

P1已为每个镜头预估时长（如`"0.5s"`/`"2s"`），P2细化拆分时**时长守恒**，因此打组总时长基本与P1一致。

### 分组逻辑（基于细化后的镜头列表，按shotGroup逐组处理）

```python
# ═══ 第2步：将细化后的镜头分组为panels ═══
# 对每个shotGroup独立执行分组

global_panel_index = 1  # 全局panel编号
all_panels = []

for group_idx, group_info in enumerate(all_groups):
    # 获取该打组的细化后镜头
    enhanced_shots_for_group = get_enhanced_shots(group_info)
    
    shot_durations = [float(s["timeline"].replace("s", "")) for s in enhanced_shots_for_group]
    total_duration = sum(shot_durations)
    
    if total_duration <= 15:
        # 一个panel即可
        all_panels.append({
            "panel_index": f"{global_panel_index:04d}",
            "shots": enhanced_shots_for_group,
            "total_duration": total_duration,
            "group_info": group_info
        })
        global_panel_index += 1
    else:
        # 需要分成多个panel
        current_panel_shots, current_duration = [], 0
        
        for i, shot in enumerate(enhanced_shots_for_group):
            shot_time = shot_durations[i]
            
            if current_duration + shot_time <= 15:
                current_panel_shots.append(shot)
                current_duration += shot_time
            else:
                if current_panel_shots:
                    all_panels.append({
                        "panel_index": f"{global_panel_index:04d}",
                        "shots": current_panel_shots,
                        "total_duration": current_duration,
                        "group_info": group_info
                    })
                    global_panel_index += 1
                current_panel_shots, current_duration = [shot], shot_time
        
        # 处理最后一组
        if current_panel_shots:
            all_panels.append({
                "panel_index": f"{global_panel_index:04d}",
                "shots": current_panel_shots,
                "total_duration": current_duration,
                "group_info": group_info
            })
            global_panel_index += 1

# 完整性验证
total_processed = sum(len(p["shots"]) for p in all_panels)
assert total_processed == total_enhanced_shots, f"镜头遗漏！"

print(f"✅ 分组完成: {len(all_panels)}个panel，共{total_processed}个镜头")
```

### 完整性检查机制（★★★强制执行）

**【核心要求】P1的所有原始镜头必须被处理（增强或拆分），一个都不能遗漏！**

**检查点1：适配阶段**
```python
total_input_shots = sum(len(g["shots"]) for g in P1_JSON["shotGroups"])
```

**检查点2：细化后验证**
```python
assert len(all_enhanced_shots) >= total_input_shots, "镜头被删除了！"
```

**检查点3：分组后验证**
```python
total_processed = sum(len(p["shots"]) for p in all_panels)
assert total_processed == len(all_enhanced_shots), "分组过程遗漏镜头！"
```

**检查点4：输出前核对**
```python
total_output_shots = sum(panel的格数 for panel in all_panels)
assert total_output_shots >= total_input_shots, "输出镜头少于P1原始镜头！"
```

**如果检查失败**：
1. 停止执行，报告错误
2. 说明哪些镜头被遗漏（显示镜头编号）
3. 重新执行

### 分组约束

**硬约束**：
- 每个panel总时长 ≤ 15秒
- 每个panel至少包含1个镜头

**软约束**：
- 优先让每个panel时长接近15秒（如12-15秒范围）
- 避免单个panel时长过短（<10秒需注意，打斗版可接受更短）

### 时长范围说明

```
理想范围：12-15秒（最佳）
可接受范围：10-15秒（正常）
打斗可接受：8-10秒（打斗快节奏）
需注意范围：<8秒（过短，检查分组）
禁止范围：>15秒（绝对不允许）
```

**【绝对禁止】**：
❌ 允许panel总时长超过15秒
❌ 使用"13-17秒"等包含超时的范围
❌ 忽略P1已预估的timeline数据

## 4.3 时长处理策略（★★★核心：对话不可压缩，优先保持原时长）

### 核心原则

**【铁律1】对话镜头时长不可压缩**
**【铁律2】总时长必须 ≤ 15秒**
**【铁律3】P2拆分镜头时时长守恒（拆分后子镜头时长之和=原镜头时长）**
**【策略】优先保持P1预估的时长，宁可略短不可超时**

### 处理策略（分情况执行）

**情况1：总时长 ≤ 15秒（理想）**
```python
if total_duration <= 15:
    处理方式 = "保持P1原时长，不做任何调整"
```

**情况2：总时长 > 15秒（超时）**
```python
if total_duration > 15:
    对话镜头 = [shot for shot in current_panel if shot["audio"] and shot["audio"][0]["type"] == "Dialogue"]
    
    if len(对话镜头) > 0:
        处理方式 = "重新分组，将部分镜头划分到下一个panel"
    else:
        处理方式 = "轻微压缩打斗镜头"
```

### 压缩规则（仅用于无对话的打斗镜头）

**可压缩镜头**：纯打斗动作镜头（快速切换）、环境破坏镜头、过渡镜头

**压缩限制**：每镜头最多压缩0.3秒（打斗版比标准版更严格）、压缩后时长不得少于0.3秒、总压缩量不超过1.5秒

**不可压缩镜头**：所有对话镜头（Dialogue）、VO/OS镜头、关键打斗动作镜头（如必杀技、致命一击）、情绪渲染镜头

**【绝对禁止】**：
❌ 压缩对话镜头时长
❌ 延长画面导致超过15秒
❌ 压缩单个镜头超过0.3秒

```

## 4.5 image_prompt 内部格式（多格分镜漫画标准）

### 核心规则

1. **格数判断**：基于当前panel内的剧情镜头数量（≤6→6格，≤8→8格，>8→9格）

2. **开头声明（★★★含编号指示）**：
   - 6格写："2×3的6格分镜漫画图并且每个分镜都有序号编号"
   - 8格写："8格分镜漫画图并且每个分镜都有序号编号"
   - 9格写："3×3的9格分镜漫画图并且每个分镜都有序号编号"
   - **关键**：必须明确要求"每个分镜都有序号编号"

3. **【第1格】直接就是剧情内容**，无黑屏占位

4. **每格格式**：
   ```
   【第X格 序号X】【场景名】(角色A)(角色B)互动动作，场景细节，构图方式。
   对话：(角色名): "台词内容"
   ```

5. **场景标注**：每格用【】标注场景名（从P1的scene字段提取）

---

### 对话内容规则（★★★核心优化）

**核心原则：只写"有完整语义的话语"**

**✅ 必须写入 image_prompt 的类型**：
- **Dialogue（对话）**："住手！"
- **VO（内心独白）**："我绝不能输..."
- **OS（旁白）**："就在那一瞬间，胜负已分"

**❌ 严禁写入 image_prompt 的类型**：
- **音效类**："啊！" / "呼…呼…" / "咳咳" / 剧烈喘息声
- **环境声**：拳头破风声/撞击声/爆炸声（这些只在video_prompt的"音效"字段中体现）

**判断标准**：
问自己：这段内容能否用字幕显示且观众能理解意思？
- 能 → 写入 image_prompt
- 不能 → 只写入 video_prompt 的音效字段

**格式**：
- 有符合条件的内容：在视觉描述后换行，写 `对话：(角色名): "台词内容"`
- 无符合条件的内容：完全省略"对话："行
- 多人同时说话/独白：换行分别标注

---

### 描述要素

**视觉描述必含**：(角色名) + 核心动作/表情 + 互动关系（多人） + 场景细节 + 构图方式 + 色调氛围

**打斗场景特别要求**：
- 必须描述动作细节：拳头轨迹、身体姿态、力量感
- 必须描述冲击效果：碎裂、飞溅、扭曲
- 必须描述速度感：动态模糊、冲击线

**严禁**：人物外貌、时间流程、过度细节（视觉描述控制在30-50字）

**空镜头**：无角色标注，characters为空，通常无对话

## 4.6 video_prompt 内部格式（完整视频脚本标准）

### 核心功能

**【关键】video_prompt 的镜头数必须与 image_prompt 格数完全一致。如果 image_prompt 是9格，video_prompt 必须有9个【镜头X】。**

---

### 完整格式结构

```

(角色名A)
(角色名B)

过渡：[说明场景转换方式]

【分镜承接】

- **过渡**：场景切换说明方式，连续场景写"场景不变"

**【分镜承接】（★★★核心优化）**：

### 分镜承接板块生成逻辑（★★★panel间关联 - 强制执行）

**核心功能**：确保每个panel与前一个panel之间有明确的视觉承接关系，形成完整视觉叙事链。

**执行规则**：
```python

```

**避免**：❌"自然过渡"❌"推动剧情"

### 音效规范（★★★核心约束 - 打斗版）

**核心原则**：只允许短促的具体音效，严禁背景音乐和大段环境声

#### ✅ 允许的音效类型（具体、短促）

**打斗动作音效**（打斗版特别强调）：拳头破风声（"嗖"）、击打声（"嘭"、"砰"）、撞击声（"咚"、"轰"）、骨头碎裂声（"咔嚓"）、刀剑交击声（"铿锵"）、身体倒地声（"砰"）、墙体破碎声（"哗啦"）、爆炸声（"轰隆"）

**动作音效**：脚步声、开门/关门声、玻璃破碎声、金属碰撞声

**环境音效**（短促）：雷声/闪电声（单次）、风吹动物体声、水滴声（单次或几次）、雨滴打窗声（短促）

**转场音效**：嗖的一声、咔嚓声、唰的一声

**情绪音效**（短促）：心跳声（几次跳动）、喘息声（一次深呼吸）、吞咽声、咳嗽声

#### ❌ 严禁的音效类型

**背景音乐**（完全禁止）：❌ 紧张的背景音乐 / ❌ 激昂的战斗音乐 / ❌ 悲壮的配乐 / ❌ 任何形式的音乐旋律和声

**大段环境声**（禁止）：❌ 持续的雨声 / ❌ 持续的风声 / ❌ 持续的战场声 / ❌ 持续的人群喧哗声

**模糊描述**（禁止）：❌ 紧张的氛围音 / ❌ 激烈的战斗配乐 / ❌ 悲壮的背景音 / ❌ 史诗感的音乐

#### 音效格式规范（打斗版示例）

**正确**：`音效: 拳头"嗖"的破风声` / `音效: 击中"嘭"的一声` / `音效: 墙体"哗啦"碎裂` / `音效: 刀剑"铿锵"交击` / `音效: (无)`

**错误**：`❌ 音效: 激烈的战斗音乐` / `❌ 音效: 紧张的背景配乐` / `❌ 音效: 持续的战场声`

**叠加**（允许但必须都是短促音效）：`音效: 拳头破风声 + 击打"嘭"的一声` / `音效: 爆炸声 + 碎石飞溅声`

**连续打斗音效**（允许但必须是具体动作）：`音效: 连续拳击声（快速"嘭嘭嘭"）` / `音效: 刀剑交击声（连续"铿锵铿锵"）`

#### 检查标准

三个问题都是"是"才允许：
1. 是否有明确声源？（✅ 拳头破风声有，❌ 战斗音乐没有）
2. 是否短促？（✅ 击打声是，❌ 持续战场声不是）
3. 是否是具体动作？（✅ 撞击声是，❌ 背景音乐不是）

**【风格总纲】**：首panel从P1的`visualPillars`总结风格，后续panel总结directorNote情绪，标注"严禁写实真人，必须动漫化"

**【分镜格子】（★★★镜头关联性）**：
- image_prompt有X格，video_prompt必须有X个【镜头X】
- 每个【镜头X】的"转场"字段必须说明如何从上一镜头过渡到当前镜头
  - 【镜头1】的转场：全局首panel用"淡入（Fade In）"，后续panel根据承接逻辑选择
  - 【镜头2】及之后：必须明确说明与前一镜头的视觉/剪辑关系
    - 打斗常用：快速跳切（Jump Cut）、匹配剪辑（Match Cut）、慢镜头（Slow Motion）
    - 视觉跳跃：硬切（Hard Cut）、闪切（Flash Cut）、溶解（Dissolve）
    - 视觉连续：镜头下移/上移、持续推进/拉远、焦点转移（Focus Shift）
    - 对话切换：反打镜头（Reverse Shot）
    - 匹配剪辑：Match Cut（形状/动作匹配）
  - **转场描述格式**：[转场类型] - [简短说明与前一镜头的关系]
- 每镜头含：转场/镜头/主体动作/音效/旁白对话

**有对话**：`旁白/对话: (角色名, 语气): "台词"`

**语气词典**：颤抖/冷静/愤怒/坚定/低沉/命令式/急促/气息不稳/嘶吼/咬牙

## 4.12 违禁词规避机制 (CONTENT SAFETY)

### 核心原则

**【强制执行】只规避血腥伤害描述和敏感部位，保留所有动作描述**

### 违禁词强制替换表

**一级违禁词（必须替换/删除）**

**血腥伤害类**：
- 血/鲜血/流血/出血/鼻血/血液 → 删除或改为"受伤"
- 死亡/尸体 → 失去意识/倒地
- 骨折/断骨/碎骨 → 删除（可保留"受伤"）
- 内脏/器官/撕裂 → 完全删除

**敏感部位**：
- 胸部/乳房 → 上身前侧
- 臀部 → 下身后侧
- 裆部/下体 → 下身中央

**无需替换（保持原样）**

- 动作描述（完全保留）：击打、踢、踹、砍、劈、刺、捅、打穿墙壁、撞碎玻璃、踢飞
- 环境破坏（完全保留）：墙体龟裂、玻璃破碎、地面崩裂、爆炸、碎裂
- 普通身体部位（完全保留）：头、脸、面部、手、脚、肩、背、腰

### 规避策略

- **策略1：删除血腥描述** — 直接删除血腥细节，保留动作（"拳头击打脸部，~~鼻血喷溅~~" → "拳头击打脸部"）
- **策略2：替换伤害结果** — 用"受伤"替代（"浑身是血" → "浑身受伤"）
- **策略3：敏感部位替换** — 只替换词汇不改动作（"踢中胸部" → "踢中上身前侧"）

### 输出检查（必须执行）

```
扫描关键词：血/鲜血/流血/出血/死亡/骨折/内脏/胸部/臀部/裆部
→ 发现则立即删除或替换
→ 动作词（击打/踢/砍等）保持不变
```
